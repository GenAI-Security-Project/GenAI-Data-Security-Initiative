# Cross-Framework Control Mapping Dataset

**Status:** Superseded by the [GenAI Crosswalk](https://github.com/GenAI-Security-Project/crosswalk). Do not add mappings here.

Machine-readable mappings of DSGAI risks to the controls of security and AI governance frameworks now live in the dedicated crosswalk repository, which covers the frameworks this folder was planned for (NIST CSF 2.0, NIST AI RMF, MITRE ATLAS and ATT&CK, ISO/IEC 42001 and 27001, CIS Controls, the OWASP Top 10s, the EU AI Act, GDPR and more).

- Browse the mappings: https://genai-security-project.github.io/crosswalk/
- Propose a mapping: open an issue or pull request in https://github.com/GenAI-Security-Project/crosswalk

This folder never held data. It is kept so existing links still resolve; [`data_validation/schemas/crossframework_mapping.schema.json`](../../data_validation/schemas/crossframework_mapping.schema.json) is kept for the same reason.
